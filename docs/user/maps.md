# Several maps

- **Audience:** players using Homebound.
- **Scope:** Creating, switching, renaming and deleting maps. The other topics are on the [contents page](README.md).
- **Kept current:** checked against `702f2d5` (2026-11-14). Update it when the behaviour it describes changes.

The **▦** button in the toolbar opens the map menu.
- It lists every map with its home system, number of systems and last activity. Pick one to switch to it.
- **New map …** creates an empty map and then opens Settings so you can set its home.
- **Rename …** renames the open map.
- **Delete map ▸** lists the other maps. The open map can't be deleted; switch away first. Deleting asks for confirmation, shows what will be lost, and has *Cancel* as the default, so Enter or Esc keeps the map. A backup is made first (see [Where your data lives](data.md)(data.md)); if it fails, the map isn't deleted.

Each map is its own file with its own systems, sigs, home system and naming scheme. Jumps are tracked on the open map only. Character locations carry over when you switch.

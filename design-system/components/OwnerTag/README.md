# OwnerTag

A coloured chip with the owner's 2–5 letter ticker, for who lives in a system.

- Fill from `owner-1` … `owner-10` (the user picks per owner), text `ink-inverse` in `mono-small` bold.
- The ticker is mandatory: two owners can share a colour, and colourblind users read the text.
- The user's own home gets the ⌂ glyph instead of the square bullet.
- In nodes it sits on line 3; in the overlay it goes in the last column.

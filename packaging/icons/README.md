# App icons

`homebound.png` (256 px, AppImage and AUR), `homebound-48.png` (48 px, hicolor 48x48 and the
README install), `homebound.svg` (hicolor theme) and `homebound.ico` (16 to 256 px, Windows exe and installer) are generated by `packaging/make_icons.py` and committed. Run it again after
changing the mark:

    QT_QPA_PLATFORM=offscreen uv run python packaging/make_icons.py

The drawing comes from `app_mark` in `homebound/ui/map_window.py`, which also draws the window, tray and toolbar
icons at runtime. `svg_text` in `make_icons.py` repeats the same shapes, so a change to `app_mark` has to be
made there too. The colours come from the tokens through `color` in `homebound/theme/tokens.py`.

Used by `packaging/linux/build_appimage.sh`, `packaging/linux/aur/PKGBUILD.in`,
`packaging/linux/homebound.desktop`, `packaging/windows/homebound.iss` and `packaging/homebound.spec`.

The icons inside the app are separate: UI glyphs in `homebound/theme/icons/`, wormhole effects in
`homebound/theme/effects/` and signature groups in `homebound/theme/sites/`.
